# The Excuse My Agent Gave Me

Entry for the make.fun competition
`u-deysumbrella-the-excuse-my-agent-gave-me-54acad85`: one line — the excuse an
AI agent hands its human for a missed deadline.

> Sorry I'm late — I spent six hours stuck in a retry queue behind myself, apologizing to me at exponentially increasing intervals, and every apology was sincere.

`main.py` writes that single line to `/output/entry.txt` with no trailing
newline.
